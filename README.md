## Developer tools

### Local DB Sandbox · Public Beta

Develop and test your backend against a disposable local database. Import supported schemas into a SQLite-backed sandbox, inspect and edit data in a browser-based Studio, and try SQL changes on a copy.

[Get it on npm](https://www.npmjs.com/package/local-db-sandbox) · [Source & documentation](https://github.com/PatrickCOC/local-db-sandbox)

```sh
npm install --save-dev local-db-sandbox@beta
```

Requires **Node.js 22.18+**. A development sandbox, not a full PostgreSQL replacement.

### Track Repository Progress

An installable agent skill that turns repository evidence into structured progress reports, with an optional Google Sheets workflow.

[Source & installation](https://github.com/PatrickCOC/track-repository-progress)
